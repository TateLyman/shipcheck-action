# Support

For action bugs, usage questions, or false-positive reports, open an issue:

https://github.com/TateLyman/shipcheck-action/issues

For `shipcheck-cli` scanner behavior, open an issue in the CLI repo:

https://github.com/TateLyman/shipcheck-cli/issues

## Manual Reviews

If Shipcheck finds launch blockers in an app you own or are authorized to inspect, fixed-scope manual reviews are available from the tool page:

https://tatelyman.github.io/tate-web-services/shipcheck.html

Manual reviews focus on auth, data rules, environment boundaries, Stripe/webhooks, deploy config, and the first paid user flow.
